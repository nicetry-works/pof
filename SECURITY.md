# Security Policy

This repository is a static documentation site (Next.js/Nextra) with no
backend, no user data, and no authentication of its own. The realistic
security surface here is a vulnerable dependency, not the site's own
code.

## Reporting a vulnerability

If you find a vulnerability — in a dependency this project pulls in, or
in how the site is built/served — please email **ervin@nicetry.works**
rather than opening a public issue. Include what you found and, if
possible, how to reproduce it. We'll acknowledge within a few days.

## Supported versions

This project doesn't maintain multiple release lines — only the latest
version deployed at [pof.dev](https://pof.dev) (tracking the `main`
branch) is supported.
